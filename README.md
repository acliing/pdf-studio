# 纸间 PDF · 轻巧的本地 PDF 工作台

一个只在本机运行的 PDF 页面编辑工具。界面为中文，双击启动后用浏览器操作，所有文件都不会上传到任何服务器。

## 直接运行 EXE（免安装）

双击 `dist/纸间PDF.exe` 即可。程序会打开一个控制台窗口并自动打开浏览器；关闭控制台窗口或按 `Ctrl+C` 停止。不需要安装 Python 或依赖。运行时缓存和临时文件放在 EXE 同目录的 `.data` 文件夹中。

## 功能

- **整理页面**：打开 PDF 后以缩略图浏览，拖动调整页面顺序，单击多选、批量删除，支持撤销与恢复原顺序，导出新的 PDF。打开目标 PDF 后还可以添加一份来源 PDF，左右两栏拖动页面：拖到目标页边缘插入，拖到目标页中间替换；来源页和输出页都可以多选删除，来源页会保留，方便反复取用。只打开一份 PDF 时就是普通的单栏整理。
- **合并 PDF**：一次添加多个 PDF，拖动文件卡片调整先后顺序，合并完成后可直接下载，或继续进入页面整理。
- **拆分 PDF**：支持三种方式：
  - 按页码范围拆分，例如 `1-3, 5, 8-10`，每一段生成一个 PDF；
  - 每 N 页一份；
  - 每页单独拆开。
  结果统一打包为 ZIP。
- **图片转 PDF**：支持 JPG、PNG、WebP、BMP、TIFF；拖动调整图片顺序，可选择 A4 / Letter / 跟随图片、自动方向、页边距，生成时不裁切图片。
- **PDF 转图片**：导出 PNG 或 JPG，支持 96 / 150 / 200 / 300 DPI，可只转换指定页码，结果打包为 ZIP。
- 全程本地处理，不上传、不联网；原始文件只读，不会被修改。

## 启动方式

1. 确认电脑已安装 Python 3.10 或更新版本。
2. 双击 `启动.bat`。
3. 浏览器会自动打开 `http://127.0.0.1:8765/`。如果 8765 被占用，会自动顺延到下一个可用端口，以启动窗口里显示的地址为准。
4. 使用完毕后，关闭启动窗口或按 `Ctrl+C` 即可停止服务。

首次启动如果缺少依赖，`启动.bat` 会尝试自动安装 `requirements.txt` 中的两个包。也可以手动执行：

```powershell
python -m pip install -r requirements.txt
```

## 使用提示

- **整理页面**：拖动缩略图排序；单击页面选中；双击看大图；右上角垃圾桶直接删除单页；`Ctrl+Z` 撤销；`Delete` 删除所选。点「添加来源 PDF」后，把右侧来源页拖到左侧页面边缘可插入，拖到页面中间可替换；来源页仍保留在右侧。
- **页面预览**：用左右方向键翻页，`Esc` 关闭。
- **切换工具**：左侧导航切换，各自的工作进度会保留在本次运行中。
- **导出文件**：浏览器会按服务端返回的文件名下载。中文文件名已做兼容处理。

## 隐私与安全

- 本地服务只绑定 `127.0.0.1`，局域网中的其他设备无法访问。
- 页面带随机访问令牌，避免其他网页调用本机接口。
- 上传与导出的临时文件保存在 `pdf-studio/.data/` 下，关闭服务后仍会保留一段时间以便下载；启动时会自动清理超过 24 小时的旧文件。
- 如果 Windows 防火墙弹窗询问是否放行，**不需要放行**；本工具不需要外部网络访问。

## 技术说明

- 后端：Python 标准库 `http.server`，无 Web 框架依赖。
- PDF 处理：PyMuPDF（页面渲染、合并、拆分、重建 PDF）。
- 图片处理：Pillow（EXIF 方向校正、格式统一、JPEG 输出）。
- 前端：原生 HTML / CSS / JavaScript，无 CDN、无构建步骤、无外部字体。
- 导出的 PDF 会重建页面对象，保留原始页面尺寸与旋转；原文件不会被原地修改。

## 常见问题

**Q：双击 `启动.bat` 没反应或窗口一闪而过？**

先看启动窗口里最后一行提示。如果窗口直接关闭，可以在 `pdf-studio` 文件夹空白处按住 `Shift` 点右键，选择“在此处打开 PowerShell 窗口”（或“在终端中打开”），然后执行：

```powershell
python server.py
```

这样能看到完整的错误信息。本项目的 `启动.bat` 已改为纯 ASCII + CRLF，避免 Windows `cmd` 在中文/UTF-8 批处理上解析失败。

**Q：提示"没有找到 Python"？**
安装 Python 时勾选 "Add Python to PATH"，或在命令行用 `py -3 server.py` 启动。

**Q：打开 PDF 时提示有密码？**
当前版本不支持加密 PDF，请先用其他工具去除打开密码。

**Q：360 / 浏览器提示"本地网络"？**
这是浏览器对 localhost 服务的正常提示。服务仅监听本机地址，不会向外部发送文件。

**Q：能处理多大的文件？**
单个文件最大 250 MB，PDF 最多 5000 页；合并最多 100 个文件，拆分最多生成 500 个文件，PDF 转图片单次最多 1500 页。具体限制以界面提示为准。
